# Day 11 — Senses: Sound

- DATE: 11-11-2026
- NAME: Senses: Sound

## Description（公式）

> How do you hear something? How do you map a soundscape? Noise pollution mapped?

## Description（日本語訳）

どうやって何かを聞く？ サウンドスケープはどう地図にする？ 騒音公害を地図にしてみては？

## 地図のテーマ

風で変わる羽田の空（城南島で聞く飛行機の音）

## 内容

羽田空港のまわりを低く飛ぶ機体の1日分の航跡を、高さのある光の線として3Dで動かす。画面の端に羽田の風（向きと強さ）と、航跡から推定した滑走路の使い方（北風運用・南風運用）を出し、風で空の道が入れ替わる様子を見せる。

主役の日は 2026年4月3日（金）。朝は北風運用で、10時台に南風運用へ切り替わり、15〜17時台は北の都心側から着陸し、18時台から元の南風運用に戻る。

見せたいのは2つ。

1. **風向きで運用が変わる瞬間**。再生は、運用が切り替わる時刻の前後30分だけゆっくりにし、それ以外は速く進める。切り替わると画面の上に「北風運用 → 南風運用」「風が南に変わり、南風運用へ」のように大きく出す。空港の南東の海の上に羽田の風の矢印（長さは風速に比例、文字はその時間の観測値）を置き、着陸が風に向かって降りるのと並べて見せる
2. **風と飛行機の音**。風の音は羽田の風速で大きさと高さを変える。飛行機の音は、入間航空祭（2026-11-03）で自分で録ったブルーインパルスの通過音を約4秒のループにし、城南島（城南島海浜公園のあたり）で聞こえる強さで大きさと明るさを変える（強いほど大きく、弱いほど高い音を削って遠くの音にする）。早送りでは1機の通過が一瞬になるので、機体が近づいたら一気に大きくし、約1秒かけて小さくする。動画では、運用が切り替わってゆっくり再生になる 10:11（JAL454、城南島から59m）と 18:20（JAL914、55m）の通過に合わせて、録った通過音（近づく→真上→遠ざかるの約10秒）をそのまま重ねる。強さは、城南島から各機体までの3Dの距離 d で `1 - exp(-Σ (300m / d)²)` とした（2秒ごと）。南風運用のときは着陸する機体が城南島の真上を低く降りてくるので音が重なり、北風の朝と、都心側から着陸する15〜17時台は静かになる。騒音の大きさ（dB）は出さない

羽田空港は、4本の滑走路（A・B・C・D）を1色で描き、航跡がその上に重なって見えるようにする。誘導路とエプロンも描き、D滑走路が誘導路の橋で空港とつながっていることがわかるようにする。城南島海浜公園は範囲をピンクで塗り、機体がその上（公園のあたりから500m以内・高度1,500ft 未満）を通ると輪を広げる。パネルにはその便数を数える（4/3 は304便）。航跡の真下の地面には薄い影を引き、どこの上を飛んでいるかがわかるようにする。背景の海岸線は白で縁取る。空港のまわりの建物は PLATEAU の3D都市モデル（大田区）で立てる。

風は、東京湾まわりのアメダス・気象台14地点（羽田・東京・江戸川臨海・練馬・府中・船橋・千葉・木更津・佐倉・我孫子・横浜・海老名・三浦・辻堂）の1時間ごとの風向・風速を、距離の2乗の逆数で重み付けして補間し、地面の高さに粒子として流す。

パネルには、2024年度の月ごとの「羽田で南寄りの風だった時間の割合」と「南風運用の割合（国交省の公表値）」を並べ、その日が1年の中でどこにあたるかを見せる。

### 調べたこと

- 城南島の上を低く通る便は、日によって大きく違う（2026-03-31〜04-07 JST）。南風の日は1日300〜400便、北風の日（4/1・4/2）は30便と2便。城南島の上を通る観測点の96%は降下中で、進む向きは南西
- 航跡から推定した運用は3つ。北風（34 に着陸、34 と 04/05 から離陸）、南風（22/23 に着陸、16 から離陸）、南風の15〜18時台（16 に着陸、22/23 と 16 から離陸）
- 国交省 FAQ（Q3・Q4）: 南風時は「海側（浦安沖）から到着し、海側（木更津沖）へ出発」、北風時は「海側（木更津沖）から到着し、海側（浦安沖）へ出発」。南風時の新しい経路は「15:00～19:00（切替時間を含むため、実質３時間程度）」
- 国交省 FAQ（Q5）: 切り替えは「管制官が、風向、風速などの気象状況に基づき、気象予報、交通量、交通流など（ときにはパイロットからの助言も得つつ）あらゆる情報を勘案しつつ判断」。数値の基準は公表資料では確かめられなかった
- 季節の傾向（国交省の公表値）: 夏は南風運用、冬は北風運用が多い。2024年度の昼間（6〜23時）の南風運用は 7月 70%、11月 12%。1日の中では午前に北風運用、午後に南風運用が多い。2026年4〜6月は昼間 42%・53%・42%
- 羽田の風（気象庁の1時間ごとの値、2024年度）で、7〜23時に南寄り（東南東〜西南西）の風だった時間の割合を月ごとに数えると、公表の南風運用の割合との相関係数は 0.98。冬（12〜2月）は南寄りの風が3割あっても、南風運用は2割前後

### 言える範囲

- 航跡は ADS-B を発信している機体だけ。受信機の配置で、低い高度まで拾える場所に偏りがある（羽田のまわりはよく拾える）
- 高度は気圧から出した値（alt_baro）で、地面からの高さではない。画面では見やすさのため高さを2.5倍にしている（`?z=1` で実寸）
- 運用は、空港から5km以内・高度600ft 未満を飛ぶ機体の向きから1時間ごとに推定したもので、公式の運用記録ではない
- 切り替えは風だけで決まるわけではない（管制官が交通量なども合わせて判断する）ので、「風で決まる」とは言い切らず、風と運用を並べて見せる
- 風の粒子は14地点の観測を補間したもので、地点のあいだの風は推定。粒子の速さは誇張している（1 m/s で約240 m/秒）。気象庁の風向は16方位、時間ごとの値は前1時間の観測
- 風の音は、羽田の風速をデータから音に置き換えたもの。飛行機の音は録った音だが、ブルーインパルス（T-4）の音で、羽田の旅客機の音ではない。大きさは城南島から機体までの距離から決めたもので、騒音の測定値でもない
- 1週間・1日分の結果なので、「いつもそう」とは言えない。季節の傾向は国交省の公表値に従う

## 使用する技術

- Python（DuckDB）→ Web 用のデータ（`scripts/prepare.py`）
- MapLibre GL JS + deck.gl（TripsLayer で航跡を光の尾つきで動かす、Tile3DLayer で PLATEAU の建物、PathLayer で滑走路、PathLayer・PolygonLayer で滑走路・誘導路・エプロン・城南島海浜公園、LineLayer で風の粒子、ScatterplotLayer で城南島の上を通ったときの輪、TextLayer で地名と羽田の風の文字）
- 背景は国土地理院の最適化ベクトルタイル（PMTiles）
- 音: ブラウザでは Web Audio API（再生中に鳴る）。動画では、録画した時刻の記録から `scripts/sound.py`（NumPy・SciPy）で同じデータから音を作り、ffmpeg で映像に重ねる。飛行機の音のループ `web/roar.wav` は `scripts/roar.py` で録画から切り出す

```sh
cd day11-sound
python -I scripts/fetch_wind.py   # 主役の日の14地点の風を取得
python -I scripts/prepare.py   # ADS-B と気象庁の値から web/ を作る
python -I scripts/roar.py      # 録った通過音から飛行機の音のループ web/roar.wav を作る
npm install
npm run dev
node scripts/shot.mjs http://localhost:5173/   # 確認用のスクリーンショット（output/web/）
npm run build                  # site/ に書き出す
node scripts/record.mjs http://localhost:5173/          # ?shot&tour を画面録画し、時刻の記録 tlog.json も保存
python -I scripts/sound.py output/live/rec-<日時>      # 音を作って重ね、output/day11-haneda.mp4 にする
```

- 公開先: [site/](https://shiwaku.github.io/30daymapchallenge-2026/day11-sound/site/)
- パネル: 右上のボタンで開け閉めできる。閉じても Day・タイトル・時刻・運用名・羽田の風は残る。状態はその端末に覚えておく（スマホでは最初は閉じる）
- PWA: マニフェスト・アイコン・Service Worker（`public/`）。ホーム画面に追加して開ける。ページと `web/` のデータは端末に保存し、電波がなくても開ける（背景地図と PLATEAU の建物は保存しないので、電波がないと出ない）
- URL パラメータ: `?t=16:30` でその時刻、`?play` で自動再生、`?tour` で録画用の自動ツアー（7:00〜19:30）、`?shot` で操作部品を隠す（録画用）、`?z=1` で高さを実寸、`?bldg=0` で建物を消す、`?wind=0` で風を消す、`?cam=経度,緯度,ズーム,傾き,向き` でカメラを決める

## データ

- 航跡: [ADSB.lol](https://adsb.lol/) の日次アーカイブ [adsblol/globe_history_2026](https://github.com/adsblol/globe_history_2026)（ODbL）。[adsb-flight-data-converter](https://github.com/shiwaku/adsb-flight-data-converter) で観測点にしたもの（2026-03-31〜04-06 UTC）から、2026-04-03 JST の羽田から半径35km・高度10,000ft 以下を取り出す。`web/` の航跡は ODbL の派生データ
- 風: [気象庁 過去の気象データ検索](https://www.data.jma.go.jp/stats/etrn/index.php)（1時間ごとの値）。羽田の2024年度分と、主役の日の14地点（`scripts/fetch_wind.py` で取得）
- 運用の割合: 国土交通省「羽田空港のこれから」[ニュースレター第19号（2025年秋）](https://www.mlit.go.jp/koku/haneda/assets/pdf/newsletter_20.pdf)（2024年度）、[羽田空港の国際線増便の実現方策 FAQ](https://www.mlit.go.jp/koku/haneda/archive/faq/pdf/06.pdf)、[第38回定期運用報告](https://www.mlit.go.jp/koku/haneda/news/20261005)（2026年4〜6月）
- 滑走路: [OpenStreetMap](https://www.openstreetmap.org/)（© OpenStreetMap contributors、ODbL）の aeroway=runway・taxiway・apron と、城南島海浜公園（leisure=park、relation 15635330）を Overpass API で取得。滑走路は中心線の両端、公園はリレーションの線をつないだ外周
- 建物: [3D都市モデル（Project PLATEAU）大田区（2025年度）](https://www.geospatial.jp/ckan/dataset/plateau)の建築物モデル（LOD2、テクスチャなし、3D Tiles、CC BY 4.0）を配信URLから直接読む
- 背景: [国土地理院ベクトルタイル](https://maps.gsi.go.jp/development/ichiran.html)（最適化ベクトルタイル）
- 飛行機の音: 入間航空祭（2026-11-03）で自分で撮った動画（`data/20261103_112631571.mp4`、Git 管理外）の、ブルーインパルスが通過する 59.6〜64.4秒の音。人の声が入らない区間を選んだ
- 出典表記: ADSB.lol（ODbL）、気象庁「過去の気象データ」（羽田ほか14地点）、国土交通省「羽田空港のこれから」ニュースレター第19号を加工して作成 / 滑走路・誘導路・公園: © OpenStreetMap contributors / 建物: 3D都市モデル（Project PLATEAU）大田区（2025年度） / 背景: 国土地理院ベクトルタイル
- 取得データ（気象庁のページ、国交省の PDF）は `data/` に置き、Git 管理外
