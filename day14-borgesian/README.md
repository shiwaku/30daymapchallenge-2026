# Day 14 — Borgesian map

- DATE: 14-11-2026
- NAME: Borgesian map

## Description（公式）

> A map so detailed it becomes the territory. Inspired by Borges' On Exactitude in Science.

## Description（日本語訳）

細かすぎて、実際の土地そのものになってしまう地図。ボルヘスの『学問の厳密さについて』に着想を得たお題。

## 地図のテーマ

1億2614万人の地図（A5 の五角形で数え、数えられなくなる所から先は格子だけにする）

## 内容

2020年の国勢調査の人口（125mメッシュ）を、地球を面積の等しい五角形に分ける格子 A5 で数えて描く。寄るほど五角形が細かくなる。人口を出すのは解像度14（約0.13km²、125mメッシュ約8個分）まで。その先は人口を消して格子だけにし、空中写真の上で解像度30（約29mm²、5mm四方ほど）まで細かくしていく。最後は写真も引き伸ばされて灰色一色になり、格子だけが残る。

- 引いて見ると地球儀で、A5 の全球の格子（解像度0の12個の五角形と、解像度1・2）が出る
- ズーム z では解像度 z+3 の五角形を出す。どのズームでも、五角形は画面でさしわたし約10〜20pxになる
- 解像度14（ズーム11〜12）で、国土地理院の空中写真を人口の色の上に乗算で重ねる（人口の色に写真の模様が乗る）。解像度15で人口の色が抜けて、写真と白い格子だけになる
- 色は1km²あたりの人口（対数で補間）。五角形はどの解像度でも面積が等しいので、色をそのまま密度として比べられる
- 五角形に触れると、その五角形の人口（約◯人）と、必ず入る幅（◯〜◯人）が出る
- 画面の左に、いまの解像度、1つの五角形の広さ、人のいる五角形の数（解像度14まで）を出す
- 動画（`?tour`）は地球儀から日本、東京へ寄り、日本経緯度原点（港区麻布台）で解像度30まで寄って終わる

お題の「a map so detailed it becomes the territory」を、格子をどこまでも細かくすると、データは途中で尽き、写真（土地）も尽きて、格子だけが残る流れで表す。

|---:|---:|---:|---:|
| 3 | 約53万 km² | 12 | 137 |
| 6 | 約8,300 km² | 129 | 3,056 |
| 9 | 約130 km² | 3,528 | 17,214 |
| 12 | 約2.0 km² | 113,929 | 30,510 |

- 人のいる125mメッシュ 2,820,831、人口の合計 126,146,099人（令和2年国勢調査の人口と同じ）。どの解像度でも五角形の人口の合計はこの数になる（スクリプトで確かめている）

### 数え方

- 125mメッシュは正方形、A5 は五角形で、境界が合わない。解像度ごとに、メッシュ（緯度経度の長方形）と五角形の重なりの面積の割合で人口を配った（メッシュの中では人が均一にいるとみなす）
  - メッシュの4隅が同じ五角形に入るなら、メッシュは丸ごとその五角形に入る
  - そうでなければ、メッシュの辺の上の点（1辺16点）が入る五角形を候補にし、shapely で重なりの面積を求める。候補の五角形でメッシュの面積の99.9%以上を覆えていることを確かめた（解像度13・14の計26メッシュだけ 99.9% をわずかに下回るが、割合は正規化している）
- A5 の親子は形として入れ子になっていない（子の五角形が親からはみ出す。`cell_to_parent` の親がその点を含まないことが約36%ある）。そのため細かい解像度から足し上げず、解像度ごとに直接配った
- 下限・上限: 五角形に丸ごと入るメッシュの人口の合計が下限、少しでもかかるメッシュの人口の合計が上限。メッシュの中の人の偏りによらず、五角形の人口は必ずこの幅に入る
- メッシュの南西端はメッシュコード（11桁）から計算した。e-Stat の境界データ（6次メッシュ）と比べて、ずれがないことを確かめた（2,000メッシュを抜き出して比較、差は 1e-13 度以下）
- 125mメッシュは人口の少ないメッシュの内訳（年齢別など）が秘匿され隣に合算されているが、人口（総数）はすべてのメッシュに出ている。使ったのは人口（総数）だけ

### 言える範囲

- 色・数字は「その五角形にかかる125mメッシュの人口を、面積の割合で配ったもの」。確かに言えるのは「◯〜◯人の間」まで
- 解像度15から先（125mメッシュの2倍より小さい五角形）は、人口の細かさが足りないので出さない
- 人口は常住地（夜間）の人口。昼間にいる人ではない（都心のビル街が暗いのはそのため）

## 使用する技術

- Python（pyarrow・pandas・shapely・pya5）で集計 → tippecanoe 2.80（WSL）でベクトルタイル → PMTiles（約29MB、Cloudflare R2）
- 解像度15〜30の格子は、MapLibre の `addProtocol` でタイルが要るたびに a5-js で計算し、@maplibre/vt-pbf でベクトルタイルにする（ファイルは置かない）
  - MapLibre はタイルのズームが25まで、レイヤーの minzoom/maxzoom が24までなので、解像度29・30はズーム25のタイルに入れ、不透明度で出し分ける
  - background レイヤーはズーム25より先で落ちるので、そこから先は世界を覆う面で塗る
- 空中写真の乗算: MapLibre GL JS 6.18 の `raster-layer-blend: "multiply"`
- MapLibre GL JS 6（地球儀表示）、Vite

## 作り方

```bash
# 1. 125mメッシュを A5 の五角形（解像度3〜14）に配る（約4分）。data/cells_rNN.geojsonl・world.geojson・stats.json
python -I -X utf8 scripts/build_cells.py <2020_pop_census_mesh125.parquet> data
cp data/stats.json data/world.geojson data-web/
# 2. ベクトルタイル（数分）。data/cells.pmtiles
wsl -d Ubuntu -- bash scripts/tiles.sh
# 3. ビューワ
npm install && npx vite --port 5190
node scripts/shot.mjs "<zoom>/<lat>/<lon>" output/xx.png
node scripts/record.mjs        # ?tour を録画して output/day14-borgesian.mp4
```
