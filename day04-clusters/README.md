## Description（日本語訳）

## 地図のテーマ

コンビニの縄張り（A5 の五角形で数える）

## 内容

コンビニ8チェーン（セブン-イレブン、ファミリーマート、ローソン、ミニストップ、セイコーマート、デイリーヤマザキ、NewDays、ポプラ・生活彩家）の店が、どこに、どう固まっているかを描く。日本を A5（地球を面積の等しい五角形に分ける格子）のセルに分け、セルごとに店がいちばん多いチェーンの色で塗る。背景の地図は置かず、セルの集まりだけで日本の形を描く。

- 全国を見るとき: 約130km² のセル（A5 解像度 9）
- 拡大すると: ズーム7から約32km²（解像度 10）、ズーム8.6から約8km²（解像度 11）に切り替わる
- 色はセルのなかで店がいちばん多いチェーン。同数のときは、同数になったチェーンの色の斜めの縞（凡例の最後）。明るさは店の数とそのチェーンの割合
- 店の点は出さない。公開するのはセルごとのチェーン別の店の数だけ
- 沖縄県は離れているので、全国を見るときは左下に同じ縮尺の小さな地図で出す

- 地方ブロック（7つ）のボタンと都道府県・市の選択: 選ぶとその範囲に合わせて表示し、外側を暗くする。右上に店舗数の上位3チェーンの割合（住所の都道府県で集計）
- 市（川越市 143店: ファミマ 39.2%・セブン 36.4%・ローソン 21.0%。埼玉県全体ではセブンが最多なので、市で見ると入れ替わる。札幌市 1,103店: セブン 30.9%・セイコーマート 29.6%・ローソン 25.0%）。市の店の数は、市の境界の中にある店を数えたもの
- 住所で探す（国土地理院の住所検索）・現在地ボタン: いちばん細かいセル（約8km²）に寄せて、そのセルのチェーン別の店の数を出す。五角形を押しても同じものが出る
- 地名: 国土地理院の最適化ベクトルタイルの注記（都道府県名・市区町村名）
- 発光: 描いた画面を縮めてぼかした写しを、明るさを足す合成（screen）で重ねる（A5 は格子で、描き方の機能は持たない）

凡例を押すと、そのチェーンだけで数え直して塗る（もう一度押すと戻る）。都道府県ごとに店がいちばん多いチェーンは、セブン-イレブン25都道府県、ファミリーマート11、ローソン10、セイコーマート1（北海道）。

お題の「things that gather together（集まってくるもの）」を、チェーンごとの店の固まり（縄張り）で満たす。セルの面積がすべて同じなので、セルの明るさ（店の数）をそのまま密度として比べられる。

### セルの大きさ

| A5 解像度 | 1セルの面積 | 店のあるセル | 店が1店だけのセル |
|---:|---:|---:|---:|
| 9 | 約130 km² | 2,048 | 19% |
| 10 | 約32 km² | 4,576 | — |
| 11 | 約8 km² | 9,724 | 35% |
| 12（使わない） | 約2 km² | 19,334 | 48% |

解像度 12 では店のあるセルの約半分が1店だけになり、店の位置をほぼそのまま示すことになるので、全国ではいちばん細かいのは解像度 11（約8km²、さしわたし約3km）までにした。ビューワもズーム11までしか拡大できない。

例外として、川越市・札幌市にかかる約8km²のセルだけは、ズーム9.8から解像度 12（約2km²）に分ける（`scripts/cities.py` → `data-web/a5-r12-cities.geojson`）。市の中では店が1店だけのセルが少ないため。

| 市 | 解像度 11（約8km²） | 解像度 12（約2km²） | 解像度 13（約0.5km²、使わない） |
|---|---|---|---|
| 川越市 | 21セル・1店だけ 19% | 49セル・1店だけ 33% | 93セル・1店だけ 67% |
| 札幌市 | 56セル・1店だけ 4% | 157セル・1店だけ 15% | 415セル・1店だけ 39% |

どちらも全国の解像度 11（1店だけ 35%）を超えない。公開した解像度 12 のセルは2市で227、うち1店だけは38（17%）。

画面とキャプチャの右上には、いま出ているセルの大きさ（A5 の解像度と1セルの面積）を出す。

## 言える範囲

- 店舗は All the Places が各社の店舗検索から集めたもの（2026-10-24 実行分）。各社の公式の店舗数や、日本のコンビニのすべてではない。All the Places が集めていないチェーンは入っていない
- 8チェーンは、All the Places の日本向けの spider でコンビニとして店を返したもの。ローソンはローソンストア100・ナチュラルローソンを、ファミリーマートはファミマ!!を、ミニストップは小型店（MINISOF・cisca）を、ポプラは生活彩家・スリーエイトを含む
- 「縄張り」は、セルのなかで店の数がいちばん多いチェーン。道のりや売上、商圏の調査ではない。セルの区切り方で結果は変わる（境目にある店がどちらのセルに入るか）
- 「いちばん近いコンビニも同じチェーンの割合」は、店がどれだけ同じチェーンの近くに出ているかの目安。理由（ドミナント出店か、駅や地域に限って出しているか）はこのデータからは言えない。NewDays の割合が高いのは、JR 東日本の駅の中に出すチェーンで、駅に固まるため
- 都道府県は住所の先頭から取った。住所が市から始まるセブン-イレブンの196店は、都道府県の分かるいちばん近い店と同じ都道府県とした
- 座標は各社のサイトが返す値のまま。位置の正しさは確かめていない

## A5 について

[A5](https://a5geo.org/) は、地球を五角形のセルに分ける離散グローバルグリッド（DGGS）、地理空間インデックス。H3 や S2 と同じ種類のもの。開発は Felix Palmer（[felixpalmer/a5](https://github.com/felixpalmer/a5)、Apache-2.0）。

- 地球上の地点を 64ビットのセル ID に変換する。解像度は 0〜30 の31段階で、いちばん細かいセルは約30mm²
- **同じ解像度のセルはすべて同じ面積の五角形**（隣り合うセルは5つ）。H3 は六角形に五角形が12個混ざり、セルごとに面積が少しずつ違う。A5 は例外なく等面積なので、点を数えて比べるときに、セルの大きさの違いによる偏りが入らない
- セル ID は自分と交差しない空間充填曲線に沿って振られている。ポリゴンを覆うセルの集まりが、短い ID の範囲で表せる（S2 に近い性質）
- v1.0 からセル ID が固定された。いま保存した ID は、今後も同じ場所を指す
- 公式ライブラリは TypeScript・Python・Rust（中身は Rust）。DuckDB（`INSTALL a5 FROM community;`）、PostgreSQL、R、QGIS、deck.gl にも対応がある

この地図では Python 版（[pya5](https://pypi.org/project/pya5/) 1.0.0）の `lonlat_to_cell` で店をセルに振り分け、`cell_to_boundary` で五角形の形を取った。

## データ

- 店舗: [All the Places](https://alltheplaces.xyz/) 2026-10-24 実行分（run 2026-10-24-13-32-37）の spider 出力 `seven_eleven_jp` `familymart_jp` `lawson_jp` `ministop_jp` `seicomart_jp` `daily_yamazaki_jp` `newdays_jp` `poplar_jp`。ライセンス: CC0（サイトの記載「The downloads provided above and the data contained therein are released under Creative Commons' CC-0 waiver.」を2026-11-02に確認）。CC0 だが出典として書く。取得したデータは `data/`（Git 管理外）に置き、リポジトリと公開ページには入れない

- 市の範囲: [国土数値情報 行政区域データ（N03）](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2025.html) 2025年（国土交通省）を加工。`scripts/cities.py` で市の面（政令市は区をまとめる）と、境界の中にある店の数（チェーン別）を `data-web/cities.geojson` に出す。今は川越市・札幌市
- 地名: [国土地理院 最適化ベクトルタイル](https://github.com/gsi-cyberjapan/optimal_bvmap)（PMTiles をそのまま読む）。住所検索: 国土地理院 住所検索 API

- 自前でクロールしたデータは使っていない

### ドラッグストア・ホームセンターをやめた理由

最初の案はドラッグストアとホームセンターだった。2026-10-24 実行分で日本の spider を調べると、ドラッグストアはウエルシア（2,952）・スギ薬局（2,084）・セイムス（1,255）・そうごう薬局（796）・トモズ（288）はあるが、マツモトキヨシは0件（エラー）、ツルハ・コスモス薬品・サンドラッグなどの spider はない。ホームセンターはカインズ・コメリ・DCM・コーナンのいずれもない。大手が欠けたまま縄張りを描くと、欠けたところが「空白の地域」に見えてしまうので、主要チェーンがそろっているコンビニにした。

## 使用する技術

- Python（pya5・scipy・pyproj）: A5 のセルへの振り分けと集計、最近傍の店（cKDTree）
- Vite 8 ＋ MapLibre GL JS 6（TypeScript）＋ pmtiles。セルの GeoJSON（解像度 9・10・11、合わせて約3.7MB）をタイルにせず、そのまま読む
- 解像度ごとにレイヤーを分け、ズームの境目で重ねて入れ替える。凡例でチェーンを選ぶと、そのチェーンだけでセルの色と明るさを計算し直す（`setData`）
- 発光は A5 ではなく描き方で作る: セルの中は暗めに塗り、縁をチェーンの色の線で内側からなぞる（ネオン管）。MapLibre の画面を 1/4 に縮めて2段階にぼかした写しを 2D canvas に描き、背景の色を引いてから `mix-blend-mode: screen` で重ねる
- 横長の画面では、地図を −24° 回して日本の北東を右に向ける（URL に位置があるときは回さない）
- 公開版は `site/`（`npm run build` の出力）。GitHub Pages では /day04-clusters/site/。データは `data-web/`（`data/` は取得データ置き場で Git 管理外）

## データの利用条件について

### 2026-11-02 の判定

All the Places はデータを CC0 で公開しているが、それは All the Places 側の宣言で、元の各社サイトの利用規約まで消えるわけではない。8社の規約を読んだ結果:

- ローソン（[規約](https://www.lawson.co.jp/kiyaku/rule.html)）と NewDays（[JR東日本クロスステーション](https://www.jr-cross.co.jp/terms.html)）は、サイトで得られる「一切の情報」「文章等のデータ等」の転載・複製・頒布・二次的使用を断っている
- セブン-イレブン・セイコーマート・ファミリーマート・ミニストップは、著作権を主張したうえで、私的使用など法律で認められる範囲を超える複製・頒布を禁じている
- デイリーヤマザキ・ポプラには規約のページが見当たらない（ポプラの店舗一覧は Google マイマップで、Google の規約が別にかかる）
- 自動取得（スクレイピング）を名指しで禁じる条項は、8社とも見当たらなかった

店の名前・住所・座標は事実で、著作物にあたらない可能性が高いが、全国の店舗一覧をまとめて配り直すことは、規約の「複製・頒布」と正面からぶつかる。この時点では、All the Places のデータを集計や派生物も含めて使わないと判定し、店の点・縄張り・集計を公開物から外した。

### 2026-11-04 の見直し

規約がぶつかるのは、店舗の情報（名前・住所・座標）を複製・頒布することに対してである。そこで、店舗の情報そのものは出さず、面積の等しいセルごとの店の数だけを公開する形に改めた。

- 公開するのは、A5 のセル（いちばん細かくて約8km²）ごとのチェーン別の店の数と、全体の集計値だけ。店の点・住所・名前・ボロノイの縄張りは、ページにもリポジトリにも置かない
- 取得したデータは手元（`data/`、Git 管理外）だけで使う
- セルの大きさは、店が1店だけのセルが多くなりすぎない細かさで止めた（上の「セルの大きさ」）
