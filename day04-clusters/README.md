# Day 4 — Clusters

- DATE: 04-11-2026
- NAME: Clusters
- ビューワ: https://shiwaku.github.io/30daymapchallenge-2026/day04-clusters/site/

## Description（公式）

> Clusters of something. Hotspots, groups, things that gather together.

## Description（日本語訳）

何かのクラスター。ホットスポット、グループ、集まってくるもの。

## 地図のテーマ

チェーン店の縄張り（コンビニの縄張り）

## 内容

コンビニ8チェーン（セブン-イレブン、ファミリーマート、ローソン、ミニストップ、セイコーマート、デイリーヤマザキ、NewDays、ポプラ・生活彩家）の店が、どこに、どう固まっているかを描く。背景の地図は置かず、店の集まりだけで日本の形を描く。

- 全国を見るとき: 12km四方の格子ごとに、店がいちばん多いチェーンの色で点を打つ。点の大きさは店の数（40店で頭打ち）、明るさはそのチェーンの割合。同数の格子は灰色
- 拡大したとき（ズーム7あたりから）: 全店のボロノイ図を作り、地面を「いちばん近いコンビニはどのチェーンか」で塗り分ける。店から2.5km以内だけを塗るので、店のない山や海は黒いまま残る。さらに拡大すると店の点を出す
- 沖縄県は離れているので、全国を見るときは左下に同じ縮尺の小さな地図で出す

3つの段階で見せる（最初は自動で進み、ボタンで行き来できる。凡例を押すと、そのチェーンだけを出す）。

1. 全国の縄張り（格子の図）。都道府県ごとに店がいちばん多いチェーンは、セブン-イレブン25都道府県、ファミリーマート11、ローソン10、セイコーマート1（北海道）
2. 固まって出すチェーン。セイコーマート・デイリーヤマザキ・NewDays・ポプラの店だけを点で出す。店の「いちばん近いコンビニ」も同じチェーンである割合が、全店に占める割合よりずっと高い
3. 大手3社は混ざり合う。セブン-イレブン・ファミリーマート・ローソンの店だけを点で出す。いちばん近いコンビニが同じチェーンである割合は、全店に占める割合より低い

お題の「things that gather together（集まってくるもの）」を、同じチェーンの店の固まりと、チェーンごとの縄張りで満たす。

- 「いちばん近いコンビニ」は、8チェーンの全店のなかで直線距離がいちばん近い別の店（アルベルス正積円錐図法の平面で測る）
- 期待値は、店の位置はそのままでチェーンを無作為に入れ替えたときの割合 (n−1)/(N−1)
- 北海道は3,050店のうちセイコーマートが1,077店（35%）で最多。セイコーマートの店は北海道のほか、茨城県92店・埼玉県10店
- 沖縄県はファミリーマート340店・ローソン271店・セブン-イレブン212店で、ファミリーマートが最多
- 12km四方の格子は1,894。店がいちばん多いチェーンは、セブン-イレブン668、ローソン349、ファミリーマート341、セイコーマート140、デイリーヤマザキ21、ミニストップ4、ポプラ1。同数が370

## 言える範囲

- 店舗は All the Places が各社の店舗検索から集めたもの（2026-10-24 実行分）。各社の公式の店舗数や、日本のコンビニのすべてではない。All the Places が集めていないチェーンは入っていない
- 8チェーンは、All the Places の日本向けの spider でコンビニとして店を返したもの。ローソンはローソンストア100・ナチュラルローソンを、ファミリーマートはファミマ!!を、ミニストップは小型店（MINISOF・cisca）を、ポプラは生活彩家・スリーエイトを含む
- 「縄張り」は、店から2.5km以内で、いちばん近い店がそのチェーンになる範囲（直線距離のボロノイ図）。道のりや売上、商圏の調査ではない。面は 120m で単純化した
- 「いちばん近いコンビニも同じチェーンの割合」は、店がどれだけ同じチェーンの近くに出ているかの目安。理由（ドミナント出店か、駅や地域に限って出しているか）はこのデータからは言えない。NewDays の割合が高いのは、JR 東日本の駅の中に出すチェーンで、駅に固まるため
- 都道府県は住所の先頭から取った。住所が市から始まるセブン-イレブンの196店は、都道府県の分かるいちばん近い店と同じ都道府県とした
- 座標は各社のサイトが返す値のまま。位置の正しさは確かめていない

## データ

- 店舗: [All the Places](https://alltheplaces.xyz/) 2026-10-24 実行分（run 2026-10-24-13-32-37）の spider 出力 `seven_eleven_jp` `familymart_jp` `lawson_jp` `ministop_jp` `seicomart_jp` `daily_yamazaki_jp` `newdays_jp` `poplar_jp`。ライセンス: CC0（サイトの記載「The downloads provided above and the data contained therein are released under Creative Commons' CC-0 waiver.」を2026-11-02に確認）。CC0 だが出典として書く
- 自前でクロールしたデータは使っていない

### ドラッグストア・ホームセンターをやめた理由

最初の案はドラッグストアとホームセンターだった。2026-10-24 実行分で日本の spider を調べると、ドラッグストアはウエルシア（2,952）・スギ薬局（2,084）・セイムス（1,255）・そうごう薬局（796）・トモズ（288）はあるが、マツモトキヨシは0件（エラー）、ツルハ・コスモス薬品・サンドラッグなどの spider はない。ホームセンターはカインズ・コメリ・DCM・コーナンのいずれもない。大手が欠けたまま縄張りを描くと、欠けたところが「空白の地域」に見えてしまうので、主要チェーンがそろっているコンビニにした。

## 使用する技術

- Python（shapely・scipy・pyproj）: ボロノイ図、店から2.5kmの円で切る処理、チェーンごとの面の結合、最近傍の店（cKDTree）、12km 格子の集計
- Vite 8 ＋ MapLibre GL JS 6（TypeScript）。GeoJSON をタイルにせず、そのまま読む（縄張りの面 6.3MB、店の点 1.3MB）
- 全国の図は格子の点（circle）、ズーム 6.9〜7.3 で縄張りの面（fill）に切り替える。面の縁はぼかした線で光らせる
- 横長の画面では、地図を −24° 回して日本の北東を右に向ける（URL に位置があるときは回さない）
- 段階2・3の店の点は、チェーンごとにまとめて描くと後のチェーンが上に重なって多く見えるので、描く順を混ぜる
- 公開版は `site/`（`npm run build` の出力）。GitHub Pages では /day04-clusters/site/。データは `data-web/`（`data/` は取得データ置き場で Git 管理外）

## 作り方

```sh
R=https://alltheplaces-data.openaddresses.io/runs/2026-10-24-13-32-37/output
for s in seven_eleven_jp familymart_jp lawson_jp ministop_jp seicomart_jp daily_yamazaki_jp newdays_jp poplar_jp; do
  curl -o data/raw/$s.geojson $R/$s.geojson
done
python -I -X utf8 scripts/prepare.py data/raw data-web
npm install
npm run dev     # http://localhost:5173/
npm run build   # site/ に出力
# 静止画: リポジトリの直下で python -m http.server 4174 を動かしてから
node scripts/screenshot.mjs   # output/day04-clusters-*.png
```
