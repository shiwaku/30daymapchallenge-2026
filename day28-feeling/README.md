# Day 28 — Senses: Feeling

- DATE: 28-11-2026
- NAME: Senses: Feeling

## Description（公式）

> The most abstract of the senses series. How would you map a feeling?

## Description（日本語訳）

五感シリーズで一番抽象的なお題。感情をどうやって地図にする？

## 地図のテーマ

楽しかった道

## 内容

自分の自転車の GPS ログで「楽しかった道」を描く（2021年の Qiita 記事の発展）

## 使用する技術

- GPX → GeoPandas → MapLibre GL JS

## データ

- 自分の GPS ログ（サイクルコンピュータ）

## 候補（手元のデータ、2026-11-09 調べ）

- 別案: jma-earthquake-data-converter（気象庁 地震月報の震度 1919〜2021年）。震度は人が揺れをどう感じたかの尺度なので Feeling に合う
