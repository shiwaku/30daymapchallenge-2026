## 地図のテーマ

都道のイチョウが色づいて散るまで

## 内容

東京都の都道の街路樹（23区、約14万本）を点で並べ、イチョウだけを「緑 → 黄色 → 落葉」と少しずつ変えていく時系列アニメーションにする。10月中旬から12月中旬まで1日ずつ進める。

色の変わり方は、気象庁が東京で観測したイチョウの黄葉日・落葉日（1991〜2020年の30年分）から決める。日ごとに「その日までに黄葉した年が30年のうち何年か」を数え、その割合に合わせて緑から黄色へ寄せる。同じように「落葉した年の割合」に合わせて黄色から落ち葉色へ寄せ、点を小さく薄くして消す。画面には「過去30年で、この日までに黄葉した年 ◯/30・落葉した年 ◯/30」と出す。

| 日付 | 黄葉した年 | 落葉した年 |
|---|---|---|
| 11/7 | 1/30（最も早い年） | 0/30 |
| 11/18 | 6/30 | 0/30 |
| 11/22 | 14/30 | 0/30 |
| 11/26 | 23/30 | 4/30 |
| 11/30 | 30/30（最も遅い年） | 10/30 |
| 12/4 | 30/30 | 15/30 |
| 12/14 | 30/30 | 30/30（最も遅い年） |

作業は Claude Code にコマンドラインで指示を出すだけで進め、データの取得・集計・Web 地図（MapLibre + deck.gl）の作成・公開まで任せた。投稿では、地図（動画）と作り方を見せる。

### 言える範囲

- 色の濃さは「ある年にこう色づいた」ではなく、「過去30年のうち、この日までに黄葉（落葉）していた年の割合」。1本の木が少しずつ色づく様子そのものを測った値ではない
- 観測は気象庁が東京で見ている1本の標本木（北の丸公園）だけ。23区のイチョウが同じように色づくわけではなく、場所による差はこの地図では表せない
- 気象庁が観測しているのはイチョウとイロハカエデだけ。街路樹に多いトウカエデ・ハナミズキ・ケヤキ・スズカケノキには観測日がないので、色を変えずに灰色で置く
- 都道の街路樹だけで、区道・公園の木は入っていない。調査年度は区によって令和2〜5年度

## 使用する技術

- Claude Code（コマンドラインで指示を出すだけで作る）
- MapLibre GL JS + deck.gl（ScatterplotLayer）。日と日のあいだを補間して滑らかに再生し、黄葉が進むほど光をにじませる

### Web 版

- 公開先: [site/](https://shiwaku.github.io/30daymapchallenge-2026/day10-prompting-only/site/)
- 色: 黄葉した年の割合で緑→黄、落葉した年の割合で黄→落ち葉色にし、散るほど点を小さく薄くする（道路沿いに点が重なるので、透明度だけでは薄く見えない）
- グロー（発光）: 大きさの違う薄い円を3枚、加算合成で重ねる。木が並ぶ道路ほど光が重なって明るくなる。光は黄葉した年の割合の2乗で強め、落葉した年の割合で弱めるので、11月末にいちばん光る（緑のうちは光が重なると色が黄色に寄るため、弱くしている）
- URL パラメータ: `?date=11-24` でその日を表示、`?play` で自動再生、`?shot` で操作部品を隠す（録画用）、`?glow=0` でグローを消す・`?glow=1.5` で強める

```sh
cd day10-prompting-only
python -I scripts/build_web.py   # data/ の CSV から web/ を作る
npm install
npm run dev                      # 確認
node scripts/shot.mjs http://localhost:5173/   # 確認用のスクリーンショット（output/web/）
npm run build                    # site/ に書き出す
```

## データ

- [都道の街路樹 街路樹（都道：23区）](https://catalog.data.metro.tokyo.lg.jp/dataset/t000014d2000000029)（東京都建設局、CC BY）
  - CSV（Shift_JIS）144,183本、樹種407種。列は樹種・区分（高木/中木）・樹高・枝張・幹周・行政区・路線名・経度・緯度
  - イチョウは 17,216本（いちばん多い樹種）
- [生物季節観測](https://www.data.jma.go.jp/sakura/data/)（気象庁）
  - 東京（地点番号662）のイチョウの黄葉日・落葉日、1991〜2020年の30年分（[累年値 CSV](https://www.data.jma.go.jp/sakura/data/download_ruinenchi.html)、いちょう黄葉 013.csv・落葉 014.csv）。最も早い・遅い年は黄葉 11/7〜11/30、落葉 11/24〜12/14
  - 平年値（同じ30年の平均）: 黄葉 11月23日、落葉 12月3日（累年値 CSV の平年値列で確認）
  - 参考: 2025年の観測日は黄葉 11月22日、落葉 12月4日
- 出典表記: 「都道の街路樹」（東京都建設局）、生物季節観測（気象庁）を加工して作成
- 取得データは `data/` に置き、Git 管理外。Web 版で使う `web/`（点の座標 1.1MB と日ごとの年数）は CC BY の加工データとして Git に入れる
