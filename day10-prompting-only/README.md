## 地図のテーマ

都道のイチョウが色づいて散るまで

## 内容

東京都の都道の街路樹（23区、約14万本）を点で並べ、イチョウだけを「緑 → 黄色 → 落葉」と少しずつ変えていく時系列アニメーションにする。10月中旬から12月中旬まで1日ずつ進める。

色の変わり方は、気象庁が東京で観測したイチョウの黄葉日・落葉日（1991〜2020年の30年分）から決める。日ごとに「その日までに黄葉した年が30年のうち何年か」を数え、その割合に合わせて緑から黄色へ寄せる。同じように「落葉した年の割合」に合わせて点を薄くし、100%で消す。画面には「過去30年で、この日までに黄葉した年 ◯/30・落葉した年 ◯/30」と出す。

| 日付 | 黄葉した年 | 落葉した年 |
|---|---|---|
| 11/7 | 1/30（最も早い年） | 0/30 |
| 11/18 | 6/30 | 0/30 |
| 11/22 | 14/30 | 0/30 |
| 11/26 | 23/30 | 4/30 |
| 11/30 | 30/30（最も遅い年） | 10/30 |
| 12/4 | 30/30 | 15/30 |
| 12/14 | 30/30 | 30/30（最も遅い年） |

作業は QGIS の中の AI（Mapsuke）のチャットに指示を出すだけで進め、データの読み込み・色分け・時系列の設定・書き出しまで任せる。投稿では、地図（動画）・最初の指示・指示の回数を見せる。

最初の指示（予定）:

```text
C:\Users\yshiw\Documents\GIS\30daymapchallenge-2026\day10-prompting-only\data\tokyo_gairoju.csv（Shift_JIS、東京都建設局「都道の街路樹」、経度・緯度列あり）を読み込んで、イチョウが黄葉して散るまでを1日ずつ見せる時系列アニメーションを作って。
- 期間は 10/15〜12/15。日付はイチョウの気象庁平年値（東京）で、黄葉 11/23、落葉 12/3
- イチョウは「緑 → 黄葉日から黄色 → 落葉日から消える」。イチョウ以外の木は小さな灰色の点で常に表示
- 範囲は23区。背景は暗めで、日付を大きく表示
- 画面内に出典「東京都建設局『都道の街路樹』(CC BY)、気象庁 生物季節観測」を入れる
- 各コマを day10-prompting-only\output\frames に書き出して
```

1回目の書き出しは黄葉日（11/23）に全部が一斉に切り替わったため、2回目の指示で過去30年の割合を使う形に直す:

```text
いまは黄葉日に一斉に切り替わっているので、だんだん色づくようにしたい。
C:\Users\yshiw\Documents\GIS\30daymapchallenge-2026\day10-prompting-only\data\jma_013.csv（いちょう黄葉）と jma_014.csv（いちょう落葉）は気象庁の生物季節観測の累年値（Shift_JIS）。地点番号662（東京）の1991〜2020年の観測日を使って、各日について「その日までに黄葉した年の割合」「その日までに落葉した年の割合」を計算して。
- イチョウの色は、黄葉の割合に合わせて緑→黄色に補間する
- 落葉の割合に合わせて点の不透明度を下げ、100%で消す
- 「黄葉まであと◯日」の表示は消して、代わりに「過去30年で、この日までに黄葉した年 ◯/30・落葉した年 ◯/30」と出す
- 凡例の注記は「色の濃さは東京（北の丸公園の標本木）の1991〜2020年の観測から。場所による差は表していません」にする
- コマは同じ frames フォルダに上書きで書き出して
```

### 言える範囲

- 色の濃さは「ある年にこう色づいた」ではなく、「過去30年のうち、この日までに黄葉（落葉）していた年の割合」。1本の木が少しずつ色づく様子そのものを測った値ではない
- 観測は気象庁が東京で見ている1本の標本木（北の丸公園）だけ。23区のイチョウが同じように色づくわけではなく、場所による差はこの地図では表せない
- 気象庁が観測しているのはイチョウとイロハカエデだけ。街路樹に多いトウカエデ・ハナミズキ・ケヤキ・スズカケノキには観測日がないので、色を変えずに灰色で置く
- 都道の街路樹だけで、区道・公園の木は入っていない。調査年度は区によって令和2〜5年度

## 使用する技術

- QGIS（Temporal Controller）
- Mapsuke（QGIS の中で動く AI エージェント、OSS）
- Web 版: MapLibre GL JS + deck.gl（ScatterplotLayer）。QGIS では表しにくい、日と日のあいだの滑らかな補間や光のにじみを出すため。Claude Code にコマンドラインで指示して作った

## データ

- [都道の街路樹 街路樹（都道：23区）](https://catalog.data.metro.tokyo.lg.jp/dataset/t000014d2000000029)（東京都建設局、CC BY）
  - CSV（Shift_JIS）144,183本、樹種407種。列は樹種・区分（高木/中木）・樹高・枝張・幹周・行政区・路線名・経度・緯度
  - イチョウは 17,216本（いちばん多い樹種）
- [生物季節観測](https://www.data.jma.go.jp/sakura/data/)（気象庁）
  - 東京（地点番号662）のイチョウの黄葉日・落葉日、1991〜2020年の30年分（[累年値 CSV](https://www.data.jma.go.jp/sakura/data/download_ruinenchi.html)、いちょう黄葉 013.csv・落葉 014.csv）。最も早い・遅い年は黄葉 11/7〜11/30、落葉 11/24〜12/14
  - 平年値（同じ30年の平均）: 黄葉 11月23日、落葉 12月3日（累年値 CSV の平年値列で確認）
  - 参考: 2025年の観測日は黄葉 11月22日、落葉 12月4日
- 出典表記: 「都道の街路樹」（東京都建設局）、生物季節観測（気象庁）を加工して作成
- 取得データは `data/` に置き、Git 管理外。Web 版で使う `web/`（点の座標 1.1MB と日ごとの年数）は CC BY の加工データとして Git に入れる
