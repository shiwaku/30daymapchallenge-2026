# 日本のスプロール現象 可視化 設計メモ

## 1. 目的

日本のスプロールの「2つの波」を地図で可視化し、性格の違いを対比して示す。

| | 第1波 | 第2波 |
|---|---|---|
| 時期 | 1960年代後半〜1970年代 | 1990〜2000年代 |
| 舞台 | 三大都市圏の郊外 | 地方都市 |
| 駆動力 | 人口流入・住宅需要 | 車社会化・大型店の郊外立地・規制緩和 |
| 形態 | 鉄道沿線への虫食い宅地化 | 幹線道路・バイパス沿いへの低密度拡散 |
| 人口 | 急増 | 横ばい〜減少でも拡大 |
| 主な制度 | 1968年 新都市計画法（線引き・開発許可） | 大店法の緩和→2000年廃止、2000年 都市計画法改正（線引き選択制・3411条例）、2006年 まちづくり三法改正 |

伝えたいメッセージ（案）
- 第1波：「人が溢れて広がった」
- 第2波：「人が増えなくても薄く広がった」

---

## 2. スコープとフェーズ

### Phase 1：全国・都市圏スケールの量的推移
- DIDポリゴンを1960→2020年の5年ごとに重ね合わせ、アニメーションで表示
- 鉄道（時系列）と重ね、沿線に沿った拡大を示す
- 全国のDID面積、人口、人口密度の推移を時系列グラフで示す

### Phase 2：特定地域の質的変化（空中写真・旧版地形図）
- 第1波の代表地域を1〜2か所選び、1960年代と1970年代をスワイプ比較
- 第2波の代表地域を1〜2か所選び、1980年代と2000年代以降を比較

### Phase 3（任意）：虫食い開発の抽出
- 対象を1路線の沿線、または1市域に限定
- 空中写真から建物・宅地を抽出（手作業でのデジタイズ、またはセグメンテーション）
- モノクロ写真になるため、精度検証の方法をあらかじめ決めておく

## 4. 指標（案）

- DID面積の推移（全国、都市圏別）
- 5年ごとのDID面積増加量（拡大速度）→ 第1波のピークを示す
- DID人口密度の推移 → 第2波の「薄まり」を示す
- 建物用地メッシュ数の増加（DID内／DID外）→ DID外の拡散を捉える
- 駅・IC・幹線道路からの距離帯別の市街地増加 → 鉄道型か道路型かの対比

## 5. 可視化の構成（案）

1. **イントロ**：全国のDID面積推移グラフ（2つの波を示す）
2. **第1波パート**：首都圏などのDIDアニメーションに鉄道を重ね、空中写真スワイプで見せる
3. **第2波パート**：地方都市の建物用地メッシュ、DID密度、大型店立地を重ねる
4. **制度タイムライン**：1968年 線引き → 2000年 大店法廃止・都計法改正 → 2006年 三法改正 → 2014年 立地適正化計画
5. **ドーナツ化との対比**：中心部の人口減と郊外の拡大を並べて示す（第6章）
6. **まとめ**：2つの波の対比、現在の「スポンジ化」へのつなぎ

形式の候補
- Webマップ（年次スライダー、スワイプ比較）
- スクロール連動型のストーリーマップ
- 静止画（発表スライド用）

## 6. ドーナツ化現象との対比

### 違いの整理
スプロールは「外側がどう広がるか（形態）」、ドーナツ化は「中心がどう空くか（人口分布）」を見る概念。

| | スプロール | ドーナツ化 |
|---|---|---|
| 見ている場所 | 市街地の縁（郊外） | 中心部と郊外の対比 |
| 現象 | 無秩序・低密度に市街地が拡大 | 中心部の夜間人口が減り、郊外が増える |
| 主な指標 | 土地利用、DID面積、開発の分布 | 夜間人口の増減（中心と周辺の比較） |
| 問題になる点 | インフラ効率の悪化、農地の虫食い、車依存 | 中心部の空洞化、昼夜間人口の差 |

### 関係
- 同時に起きやすい：中心から出た人の受け皿が無秩序な郊外になれば、スプロールになる
- 独立もしうる
  - 中心部の人口が減らなくても、郊外が無秩序に広がればスプロール
  - 郊外が計画的なニュータウンでも、中心が空けばドーナツ化
- 2つの波との対応
  - 第1波：東京都心部では1960年代から人口が減り続け、郊外ではスプロールが進行。1990年代後半に「都心回帰」へ転換
  - 第2波：地方都市でスプロールと中心市街地の空洞化（シャッター街化）がセットで進行

### 可視化への組み込み（案）
- 市区町村またはメッシュ単位の人口増減率を、中心〜周辺で色分け（ドーナツ型の分布を示す）
- 都心からの距離帯別の人口増減グラフ（年代ごとに「谷」の位置が外へ移る様子）
- スプロール指標（土地利用・DID）と人口増減を並べ、「どこで人が減り、どこが広がったか」を対比
- 東京都心3区などの人口推移で、ドーナツ化から都心回帰までの流れを示す

### 追加データ
| データ | 提供元 | 年次 | 用途 | 備考 |
|---|---|---|---|---|
| 国勢調査 市区町村別人口（再掲） | e-Stat | 1920〜 | 中心と周辺の増減比較 | 合併による境界補正が必要 |
| 国勢調査 地域メッシュ統計（再掲） | e-Stat | 1970年代〜 | 距離帯別の増減 | |

## 8. 課題・リスク

- DIDは人口密度4,000人/km²以上の地区なので、低密度の虫食い開発を過小評価する
- 1960年代は面的な土地利用データがなく、空中写真や地形図頼みになる
- 市町村合併により、市区町村単位の時系列比較には境界の補正が必要
- 旧版地形図・空中写真の二次利用条件を確認する必要がある
- 大型店データは有料で、オープンな代替が乏しい
- 空中写真からの抽出（Phase 3）は工数が大きく、精度検証が難しい
