## Description（日本語訳）

マップチャレンジの定番。線で地図を作る。

## 地図のテーマ

線はつながっている。列車は来ない（鉄道の太さ＝本数）

## 内容

路線図では山手線もローカル線も同じ太さで描かれるが、走っている列車の数はまるで違う。全国の鉄道を、平日1日に走る列車の本数で描き直す。背景の地図は置かず、線だけで日本を描く。

4つの段階で見せる（最初は自動で進み、ボタンで行き来できる）。

1. 路線図のように、どの線も同じ太さで描く
2. 線の太さを本数に合わせる（太さは本数の平方根に比例）。東京・大阪の周りだけが太くなり、地方の線は細くなる
3. 本数の少ない線を色で示し、少し太くする。1時間に1本より少ない線（片道1日18本未満）は赤で、2026年版では営業キロの約40%（約9,750km）。30分に1本より少ない線（18〜36本未満）はオレンジで、約25%（約5,960km）
4. 本数が0の区間（14区間・約237km）を点線で示し、理由（災害で運休中など）を添える

段階3では、赤とオレンジの線をぼかした線で2重に縁取り、光らせる。目印に各地方の中心駅19駅の名前を出す（段階4では注記と重ならないよう消す）。駅の位置は、同じ gtfs-gis.jp 2026年版の事業者別・駅別データにある JR の駅の座標。

数字はすべて、ビューワがデータから計算して出す。

## 言える範囲

- 本数は、平日に走る定期列車の1日あたりの本数（上りと下りの平均）。特急など特別料金の要る列車は原則含まず、新幹線も含まない。そのため、特急だけが走る区間は0本になる
- 区間別のデータなので、同じ区間を走る路線・事業者の列車は合算されている
- 2026年3〜4月の時刻表から数えたもの（公開元はベータ版としている）
- 営業キロの合計（約24,100km）は、このデータの区間の営業キロを足したもの。日本の鉄道の総延長ではない。営業キロのない4区間は合計から外した
- 「1時間に1本」「30分に1本」は、朝6時から夜0時の18時間でならした目安（18本・36本）。時間帯ごとの本数はこのデータにはないので、朝夕に集中して走る線もならして数えている

## 使用する技術

- Python（列名をそろえ、片道あたりの本数を足すだけ。値は変えない）
- Vite 8 ＋ MapLibre GL JS 6（TypeScript）。約2,150区間なので、タイルにせず GeoJSON をそのまま読む
- 線の太さは `line-width` の式に本数を入れ、段階の切り替えでは一定の太さから本数の太さへ少しずつ変える
- 日本は南西から北東へのびているので、横長の画面では地図を38度回して北東を右に向ける。回したあとの線の広がりで拡大率を決める
- 公開版は `site/`（`npm run build` の出力）。GitHub Pages では /day02-lines/site/

## 作り方

```sh
curl -o data/raw/unkohonsu2026_kukan.geojson https://gtfs-gis.jp/railway_honsu/data/unkohonsu2026_kukan.geojson
python -I scripts/prepare.py data/raw/unkohonsu2026_kukan.geojson data/kukan2026.geojson
npm install
npm run dev     # http://localhost:5173/
npm run build   # site/ に出力
```
