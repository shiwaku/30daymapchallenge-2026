# Day 6 — Vintage

- DATE: 06-11-2026
- NAME: Vintage
- ビューワ: https://shiwaku.github.io/30daymapchallenge-2026/day06-vintage/site/

## Description（公式）

> Spin up your time machine and do a map which looks like a historical map, or maybe the theme itself should be vintage.

## Description（日本語訳）

タイムマシンを起動して、昔の地図のように見える地図を作ろう。あるいはテーマそのものを昔のものにしてもいい。

## 地図のテーマ

首都高ができていく（1955→2025）

## 内容

隅田川沿いの東側の首都高が、開通した年に、その年代の空中写真の上に立ち上がっていく様子を、時系列アニメーション（約26秒）で見せる。お題の「タイムマシン」に、背景の空中写真を年代ごとに切り替えることで答える。

- 範囲: 都心環状線の東半分（江戸橋JCT〜京橋〜銀座〜汐留〜浜崎橋）、1号上野線、1号羽田線（芝浦まで）、6号向島線（千住新橋まで）、7号小松川線、9号深川線。すべて23区の中
- 背景の写真は、その年代のものに切り替える
  - 1945〜50年（米軍撮影）
  - 1961〜69年
  - 1965年頃（江戸橋JCT 付近だけ。国土地理院 過去の地形データ）
  - 1974〜78年、1979〜83年、1984〜86年、1988〜90年
  - 現在
- 写真は夜のように暗く、青みを帯びた色に沈める
- 開通した区間は、その瞬間に白く光り、開通した年代の色（1960年代は金、70年代は橙、80年代は赤）に落ち着く
- 引いた画面では線で、寄った画面では高架の3D（高さは点群で測ったもの）で見せる
- 開通の場面ではカメラが寄り、公式の開通日を字幕に出す。寄る場面は5つ
  - 1962年 京橋〜芝浦（首都高で最初の区間、築地川・汐留）
  - 1963年 江戸橋JCT（首都高で最初のジャンクション）
  - 1971年 両国JCT（6号・7号）
  - 1980年 9号深川線
  - 1982年 6号の北への延伸
- 寄った画面では、高架の上を車のライトのような光の粒が流れる
- `?area=pilot` で、試作の範囲（江戸橋JCT〜箱崎JCT、約20秒）を開く

## 言える範囲

- 開通年は国土数値情報 高速道路時系列（N06）の値。東側の路線は、首都高速道路株式会社の「沿革・歴史」と年の単位で全部合うことを確かめた。字幕の開通日（月日）は「沿革・歴史」のもの
- 区間の形は地理院ベクトルタイルの道路中心線。N06 の線から40m以上離れていて開通年が付かない線（ランプなど）は、つながっている線から開通年を引き継いだ。それでも決まらない線（約4km、主に範囲の端のランプ）は描いていない
- トンネル（都心環状線の東半分に約0.8km）は描いていない。掘割（築地川の区間など）は、fill-extrusion で地面より下に描けないので、地面の上に薄く描いた
- **高架の高さ**
  - 東京都 区部点群データ（2024年）で、道路中心線に沿って5mおきに測った。路面の高さは半径1.5mの点の上位10%、周りの地面の高さは半径25mの地盤点の80パーセンタイルとし、その差を高さとした
  - 高架にかかる131図郭のうち、高架の長さの多い順に70図郭（高架の長さの約80%）を測った。測っていない所は、つながった点の高さからなめらかに埋めた
  - 外れ値（上の標識や交差する高架を拾った値）は除いた。坂の勾配は8%までに抑えた
  - 高さは、今の高架の高さで描いている。開通した年の高さではない
- **背景の写真**
  - 写真の年代は、地理院タイルの年代区分（撮影期間）
  - 1961〜69年の写真は場所によって撮影年が違い、東側では開通の前と後が混ざる（29地点を目で確かめた）
    - 開通の後: 芝浦、銀座・築地の掘割、汐留
    - 開通の前: 日本橋川の呉服橋〜江戸橋、楓川、昭和通り
  - そのため1962年の区間は、写真にもう写っている所に立ち上がる
- 道路の幅（9m）は描くための値で、実際の車線の数による幅ではない

## 使用する技術

- Python（GeoPandas・laspy・SciPy）で、道路中心線に開通年と高さを付ける
  - 高さを線ごとに1つの値にすると、つなぎ目が段になる。そこで4mおきの点ごとに持たせ、線のつながりの網の上で、測った値に弱く寄せながら隣の点の平均で埋めた（反復で解く）
- MapLibre GL JS 6.16 の fill-extrusion（高架・橋脚・光の粒）と line（引いた画面）
- 発光: Day 5 と同じく、道路だけを描いた2枚目の地図を同じカメラで重ね、CSS の `filter: blur()` でぼかして `mix-blend-mode: screen` で乗せる
- **毎コマの更新:** 地物ごとに値が変わる式を入れ直したり、`visibility` を切り替えたりすると、MapLibre はそのたびに道路を作り直し、部品が多いと追いつかない。そこで次のようにした
  - 開通年ごとにレイヤを分け、毎コマ変えるのは「レイヤ1つにつき1つの値」の色と不透明度だけにした
  - 立ち上がりは、寄る場面の範囲の区間だけを `feature-state` で動かした
  - 光の粒は、位置で8組に分け、組ごとに色を変えて流した
- Vite 8（TypeScript）。`site/` にビルドする
- 録画は Playwright の画面録画（コマ撮りではない）

## 作り方

```sh
npm install
# 道路中心線（地理院ベクトルタイル z16）
python scripts/fetch_rdcl.py 139.740 35.640 139.910 35.746 data/east/gsi_rdcl.geojson
# 高さ（点群の図郭を1枚ずつ取得して測り、消す）
python scripts/measure_las.py data/east/east_rdcl_measured.geojson data/east/heights_xy.csv <図郭番号...>
# 開通年・なめらかな高さ → web/east/roads.geojson, lines.geojson
python scripts/prepare_smooth.py data/east/east_rdcl.geojson web/east \
  data/east/heights_xy.csv:data/east/east_rdcl_measured.geojson data/pilot/heights_xy.csv:data/pilot/gsi_rdcl.geojson \
  --lights 139.755,35.655,139.772,35.672 139.772,35.679,139.786,35.689 139.783,35.684,139.800,35.700 139.785,35.663,139.805,35.684
# 1965年頃の写真（過去の地形データ KT657Y）の江戸橋JCT 付近の切り出し → web/pilot/kt657y.png, kt657y.json
#   （配布サーバの KT657Y から切り出した data/pilot/kt657y_crop.tif を読む。道路を作る部分は古い作り方で、今は使っていない）
python scripts/pilot_prepare.py
# 1961〜69年の写真に高架が写っているかの確認用の一覧
python scripts/check_old10.py output/check_old10_east.jpg 139.745 35.630 139.800 35.725 上野,羽田,都心環状

node scripts/record.mjs "http://localhost:4174/?play" output/day06-shutoko.mp4 1280x720
```
