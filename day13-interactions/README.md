# Day 13 — Interactions

- DATE: 13-11-2026
- NAME: Interactions
- ビューワ: https://shiwaku.github.io/30daymapchallenge-2026/day13-interactions/site/

## Description（公式）

> Interactions between things, or maybe the result would be an interactive map?

## Description（日本語訳）

物と物とのあいだのやり取り。あるいは、結果がインタラクティブな地図になるかも？

## 地図のテーマ

自宅から私事へ、市区町村をまたぐ流れ（東京都市圏の OD 量図）

## 内容

第6回東京都市圏パーソントリップ調査（2018年）の表d-1「目的種類別代表交通手段別OD表」から、目的種類「自宅－私事」（自宅を発地とし、買い物・食事・通院・娯楽などの私事の目的地を着地とするトリップ）を市区町村（政令指定都市は区）ごとにまとめ、市区町村をまたぐ流れ（OD 量）を線で描く。市区町村どうしのやり取りを描き、ブラウザで選んで見られるようにして、お題の2つの読み方に両方で答える。

- 線は発地（自宅）から着地（私事の目的地）へ向かう曲線で、先に矢印を付けた。太さはトリップ数に比例する。A→B と B→A は、進む向きの右側にふくらむので左右に分かれる
- 全体表示では 1,000トリップ/日以上の組（744本）を描く
- 市区町村をクリックすると、そこを発地とする流れ（内外トリップ、橙）と着地とする流れ（外内トリップ、紫）だけになる。その市区町村の中に、内々トリップ（発地と着地が同じ市区町村）を輪の矢印 ↻ と数で示す。パネルに内々・内外・外内の数と、相手の市区町村の上位5つを出す
- 線にマウスを乗せると、発地→着地のトリップ数と、逆向きの数を出す
- 背景に市区町村名（白）、乗降客数の多い60駅（水色）、鉄道路線（灰色）を描く
- URL に `?m=世田谷区` を付けるとその市区町村を選んだ状態で開く。`?core` で東京駅から約40kmの範囲に寄せる
- 投稿用の比較画像: `poster.html`（東京23区・横浜市・さいたま市・千葉市の区どうしの流れを同じ縮尺で2×2に並べる。地図は `?bare&fit=横浜市&z=10.15&min=300`）と `poster-wards.html`（池袋・渋谷・新宿・千代田区を選んだ画面を同じ縮尺で並べる。地図は `?bare&m=豊島区&z=11.2`）。`node scripts/poster.mjs [ページ] [出力]` で撮る

主な数字（平日1日あたり、代表交通手段が鉄道・バス・自動車・自転車・徒歩のもの）:

| 項目 | トリップ |
|---|---|
| 自宅－私事（計画基本ゾーンどうし） | 10,626,702 |
| うち内々（発地と着地が同じ市区町村） | 7,529,520（70.9%） |
| うち市区町村をまたぐ | 3,097,182（29.1%、5,988組） |
| 　うち都心5区（千代田・中央・港・新宿・渋谷）の外から5区へ | 392,962（市区町村をまたぐ分の12.7%） |
| 地図の全体表示に描いた組（1,000トリップ以上） | 1,886,612（744組） |

例: 世田谷区は内々 174,924、内外 89,868（着地の1位は渋谷区 15,345）、外内 48,861（発地の1位は目黒区 9,757）。

## 言える範囲

- 2018年の平日の調査（抽出調査を拡大した値）。休日、コロナ禍以後の変化は表れない
- 単位はトリップで、人数ではない
- 「自宅－私事」は自宅から出かけたトリップだけ。勤務先や買い物先から別の私事へ向かうトリップ（目的種類「私事」）は入らない。たとえば仕事帰りの買い物は入らない
- 発地は自宅だが、集計は自宅のある場所（住所）ではなく、トリップの発地のゾーンで行っている
- 抽出調査なので、小さい組ほど誤差が大きい。相対誤差30%以内の目安（5,136トリップ以上）を満たす組は52しかない。それより小さい線は、大小の目安として見る。表d-1 に値がない組（例: 大宮区→川越市）は、標本に入らなかったということで、移動がゼロとは言えない
- 発地か着地が「○○（その他）」「以下不明」のトリップ（圏域内の自宅－私事の約2%、251,294）は、場所が分からないので入れていない。都市圏の外が発地・着地のトリップも入れていない。代表交通手段が二輪車・その他・不明のものも除いた
- 線の端は市区町村のおおよその中心（いちばん大きい部分の重心。外れるときは内側の点）で、実際の発地・着地ではない。線は通った道ではない
- 市区町村の大きさは都心ほど小さく郊外ほど大きいので、市区町村をまたぐかどうかは、移動の距離とは一致しない
- 計画基本ゾーンが複数の町村にまたがるところ（16ゾーン）は、町村をつないで1つにした（例: 東松山市・吉見町、皆野町・東秩父村・長瀞町）
- 鉄道路線は2024年のもので、2018年より後に開業した区間（相鉄・JR直通線、相鉄・東急直通線など）も入っている。背景の目安として描いた

## 正しさの確かめ

`scripts/verify.py`（データ）と `scripts/verify_map.mjs`（地図）で確かめた。結果はすべて一致した。

1. 表d-1 の全計の行が、協議会の公表値（提言本編 p.14 図2-14 目的別、p.15 図2-16 代表交通手段別、2018年）と0.5万トリップ以内で一致する。例: 私事 2,011万（自宅－私事 1,127.0万＋私事 884.5万＝2,011.5万）、鉄道 2,418万（2,418.4万）
2. 自宅－私事のゾーン別の行と「（その他）」「以下不明」の行の合計が、表自身の圏域内合計（11,090,414）と一致する
3. 市区町村にまとめても、内々＋市区町村間の合計が計画基本ゾーンどうしの合計（10,626,702）と一致し、組の重複がない
4. ゾーン名の市区町村名で別に足し直した値が、5,589組すべてで一致する
5. ブラウザで描かれた線が 1,000トリップ以上の組と同じ744本で、どの線も発地から着地へ向かい、矢印の向きが線の向きと合い、往復の1,295組がすべて左右に分かれている

## 使用する技術

- Python（pandas で d-1 を読む、GeoPandas・Shapely でゾーンを市区町村にまとめ、となりどうし・ラベル位置・駅・路線を作る）
- Vite 8 ＋ MapLibre GL JS 6（TypeScript）。流れの線は、市区町村の中心どうしを結ぶ2次ベジェ曲線をブラウザで作り、line レイヤで描く。矢印は SDF の三角形を symbol レイヤで線の向きに回す
- 線の太さはトリップ数に比例（ズームで太さを変える）。線の下に背景色のふちを敷き、重なった線を見分けやすくした
- 引いて見るときは、トリップの多い市区町村だけ名前を出す
- スクリーンショットと地図の確かめは playwright-core（Chrome）
- 公開版は `site/`（`npm run build` の出力）。GitHub Pages では /day13-interactions/site/。`web/` を `../web/` で読む

## 作り方

```sh
# data/ に次を置く（Git 管理外）
#   pt/d-1.zip   協議会の「データの提供」（https://www.tokyo-pt.jp/data/01_02）の第6回（H30）基礎集計から
#   pt/H30_gis/  https://www.tokyo-pt.jp/static/hp/file/data/H30_gis.zip を展開
#   pt/S12/      国土数値情報 S12-23 の UTF-8 版 S12-23_NumberOfPassengers.*
#   n02/         国土数値情報 N02-24 の UTF-8 版 N02-24_RailroadSection.*
python -I -X utf8 scripts/build_pt.py data/pt web     # web/zones.json（ほかに使わないファイルも書く）
python -I -X utf8 scripts/build_muni.py data/pt web   # web/muni.json ほか
python -I -X utf8 scripts/verify.py data/pt web       # 公表値・表の合計との突き合わせ
npm install
npm run dev     # http://localhost:5173/
node scripts/verify_map.mjs http://localhost:5173/   # 地図の線の本数・向き
node scripts/shot.mjs http://localhost:5173/         # output/ にスクリーンショット
node scripts/poster.mjs poster.html output/day13-4cities.png        # 4都市の比較画像
node scripts/poster.mjs poster-wards.html output/day13-4wards.png   # 4つの区の比較画像
npm run build   # site/ に出力
```

はじめは計画基本ゾーン（615）どうしの全目的の OD 量図で作り、そのあと自宅－私事の移動時間・距離、ゾーン単位の自宅－私事に作り直してから、市区町村単位の自宅－私事の OD 量図にした。
