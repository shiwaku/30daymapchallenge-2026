# Day 13 — Interactions

- DATE: 13-11-2026
- NAME: Interactions
- ビューワ: https://shiwaku.github.io/30daymapchallenge-2026/day13-interactions/site/

## Description（公式）

> Interactions between things, or maybe the result would be an interactive map?

## Description（日本語訳）

物と物とのあいだのやり取り。あるいは、結果がインタラクティブな地図になるかも？

## 地図のテーマ

人はどこへ通うか

## 内容

2020年国勢調査の従業地・通学地集計から、15歳以上の人が「住んでいる市区町村」から「仕事・学校のある市区町村」へ通う人数（OD）を、線（deck.gl の ArcLayer）で描く。線は住んでいる所（青）から通う先（橙）へ色が変わり、人数が多いほど太い。お題の2つの読み方に両方で答える。市区町村どうしのやり取りを描き、ブラウザで選んで見られるようにした。

- 開くと全国表示。多い順に2,500本の流れを描く（この2,500本で 12,912,729人。市区町村をまたいで通う人の47.3%）
- 市区町村をクリック（または名前で検索）すると、そこから出て行く流れと、そこへ入って来る流れに切り替わる。パネルに、そこに住んで通勤・通学する人の数、同じ市区町村の中で通う割合、ほかの市区町村から来る人の数、出て行く先・来る元の上位5つを出す（上位の名前をクリックするとそこへ移る）
- 「通勤＋通学／通勤／通学」と「出入り両方／出て行く／入って来る」を切り替えられる
- 線にマウスを乗せると、どこからどこへ何人か（通勤・通学の内訳）を出す
- URL に `?m=13101`（全国地方公共団体コード）を付けるとその市区町村から開く。`&mode=work|school`、`&dir=out|in` も使える

主な数字（15歳以上の就業者・通学者）:

| 項目 | 人数 |
|---|---|
| 住んでいる市区町村ごとに数えた15歳以上の就業者・通学者 | 62,919,607人 |
| うち自分の市区町村の中で従業・通学（自宅で従業を含む） | 33,576,913人（53.4%） |
| うちほかの市区町村で従業・通学 | 27,802,940人（44.2%） |
| 　うち通う先の市区町村が「不詳・外国」 | 511,931人 |
| うち従業地・通学地「不詳」 | 1,539,754人（2.4%） |
| 市区町村をまたぐ流れ（通う先が分かる分）の合計 | 27,291,009人（270,314組） |
| ビューワに載せた流れ（10人以上の組） | 26,852,974人（71,587組、上の98.4%） |

多い組: 世田谷区→港区 39,474人、大田区→港区 36,900人、世田谷区→千代田区 36,662人、世田谷区→渋谷区 33,080人、大田区→品川区 32,341人、仙台市太白区→仙台市青葉区 28,653人（いずれも通勤＋通学）。

## 言える範囲

- 2020年10月1日時点の国勢調査（コロナ禍の最中）。そのときの回答をそのまま数えたもので、在宅勤務がどう答えられたかは確かめていない
- 数えているのは15歳以上の就業者と通学者（第3表の「うち15歳以上就業者・通学者」）。15歳未満の通学者は含めない。「通勤」は15歳以上就業者、「通学」は15歳以上通学者
- 常住地（住んでいる所）→従業地・通学地（仕事・学校のある所）の組で、通う頻度・交通手段・時間帯は分からない。単身赴任先などの「住んでいる所」は国勢調査の常住地の決め方による
- 単位は市区町村。政令指定都市は区ごと、東京都は特別区ごと（1,896単位）。同じ政令市の中で区をまたぐ通勤・通学も「ほかの市区町村へ」に入る
- 通う先が「不詳」の人（1,539,754人）と、ほかの市区町村で従業・通学しているが通う先が「不詳・外国」の人（511,931人）は線に入れない。後者は第3表の注1により、常住地と同じ市区町村の欄に計上されているので、その欄（常住地＝通う先）は使わない
- 線の端は市区町村の形のおおよその中心（いちばん大きい部分の重心。外れるときは内側の点）で、実際の家や職場の位置ではない。線は直線距離の弧で、通る道ではない
- ビューワは10人以上の組だけを載せている（全体の98.4%の人数）。パネルの人数（住んでいる人、ほかから来る人）は、切る前の全件から数えた
- 全国表示は多い順の2,500本だけ。大都市の中の短い流れが上位を占めるので、地方どうしの長い流れはほとんど出ない
- 2020年の数字で、いまの通勤・通学ではない

## 使用する技術

- Python（openpyxl で e-Stat の Excel を読む、GeoPandas・Shapely で市区町村の形と線の端の点を作る）
- Vite 8 ＋ MapLibre GL JS 6 ＋ deck.gl 9（`ArcLayer` を `MapboxOverlay` で MapLibre に重ねる。TypeScript）
- 絞り込み（選んだ市区町村の出入り、通勤・通学の切り替え）はブラウザの JavaScript で配列から引く。案の段階では DuckDB-WASM を考えていたが、載せるのが7万組ほどなので使わなかった
- 線の太さは人数の平方根に比例（ピクセル単位）。引いて見るときは細くする（ズーム9で1倍、全国表示で0.3倍）。人数の少ない線は薄くする
- スクリーンショットは playwright-core（Chrome）
- 公開版は `site/`（`npm run build` の出力）。GitHub Pages では /day13-interactions/site/。`web/` を `../web/` で読む

## 作り方

```sh
# 1. e-Stat の第3表（総数（男女）、47都道府県分の Excel）を data/estat/ に置く
#    https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=0
#    ID は 000032214148（北海道）〜。e-Stat の「表番号 3」の一覧で「総数（男女）［○○（常住地）］」のもの
# 2. 国土数値情報 N03（2020年）を data/n03/ に展開
curl -L -o data/N03-20200101_GML.zip https://nlftp.mlit.go.jp/ksj/gml/data/N03/N03-2020/N03-20200101_GML.zip

python -I -X utf8 scripts/prepare_od.py data/estat data/work                                  # 約7分。od.csv・origins.csv
python -I -X utf8 scripts/build_web.py data/n03/N03-20_200101.shp data/work web                # web/ に出力
npm install
npm run dev     # http://localhost:5173/
npm run build   # site/ に出力
node scripts/shot.mjs http://localhost:5173/   # output/ にスクリーンショット
```

`prepare_od.py` は、地域識別コードが 0（区）・2（市）・3（町村）の行だけを使う（a は都道府県、1 は政令市・特別区部の合計）。`build_web.py` は、OD の流出の合計が第3表の「他市区町村で従業・通学」から「不詳・外国」を引いた数と全単位で一致することを確かめている。
